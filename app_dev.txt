Key Notes — Mobile App
14 mobile-only screens — these are fully new builds with no web equivalent. This is where the main Phase 2 development cost sits.
Camera integration — document and car photo uploads use the device camera directly. Visual checklist with checkmarks per angle.
Push notifications — approval status changes, document expiry reminders (30 days), billing due dates.
No admin panel on mobile — admin always works from desktop browser. Not included in the mobile app.
Offline screen — bilingual no-internet screen with retry button. Required for Bangladesh network conditions.
Recommended stack — React Native or Flutter using the same Laravel backend API from Phase 1.
